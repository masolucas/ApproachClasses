How to update the arcade

  1. Open games.json (the file from your repo), or Load from website if this page is on your site.
  2. Import team entries: choose one or more teamname_arcade.json files. Workbook team files (_workbook.json) also work.
  3. Fix anything in red. Check anything in orange. Also read each entry for students’ full names: team names only.
  4. Download games.json, then upload it to the arcade folder, next to index.html. Put each game file in games/ with the file name shown on its entry.
